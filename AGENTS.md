# Agent rules — WMS

Shared rules for any AI coding agent (Claude Code, Cursor, Codex).

1. Start at `docs/discovery.md`. It lists every document, its path and its lifecycle status. Do not guess paths.
2. Read `docs/Guidelines.md` for the reading order, then only the files your task needs.
3. Explore, plan, implement, verify. Get approval for the plan before writing files.
4. Use semantic design tokens only. No hardcoded colours or pixel values.
5. Follow the Thai copy rules in `docs/foundation/` (voice, glossary, grammar).
6. Run `npm run lint` and `npm test` before you hand work back.
7. No emoji in any file.

Claude-specific rules: `CLAUDE.md`. Product context: `PRODUCT.md`.
