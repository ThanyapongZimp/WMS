# docs/

Project knowledge that is not a BMAD planning artifact. Configured as BMAD `project_knowledge` (`_bmad/config.toml`), so BMAD skills read it.

| Folder | Holds |
|---|---|
| [`decisions/`](decisions/CLAUDE.md) | Decision log index + ADRs for decisions with no other source doc |
| [`conventions/`](conventions/CLAUDE.md) | Code, UI, docs and git conventions (index points to source docs) |

Repo tooling (e.g. the doc link checker) lives in `scripts/`, not here.

Add a folder here only with its own `CLAUDE.md`, and update the root `CLAUDE.md`.
