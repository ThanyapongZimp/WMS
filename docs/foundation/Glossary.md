# Glossary

**Status:** `Trial`

Mandatory terms. Vale enforces the "Don't" column (`styles/WMS/WMSTerms.yml`). This file is exempt from Vale because it lists the banned words on purpose.

## General terms

| Term | Context | Do | Don't |
| :--- | :--- | :--- | :--- |
| Sign in / Log in | Verb, the act of signing in | เข้าสู่ระบบ / `Log in` | ล็อกอิน, `Sign in` mixed with `Log in` |
| Login | Noun or adjective, the sign-in screen | หน้าเข้าสู่ระบบ / `Login page` | `Log in page` |

## WMS terms

| Term | Context | Do | Don't |
| :--- | :--- | :--- | :--- |
| Putaway | Storing goods into a location | จัดเก็บเข้าพื้นที่ (`Putaway`) | เอาของไปวาง, เก็บของ |
| Pick | Picking goods for an order | หยิบสินค้า (`Pick`) | แพ็คสินค้า, เบิกของ |
| Wave | A group of pick work | รอบการหยิบ (`Wave`) | กองออเดอร์, ชุดบิล |
| Short Pick | Bin holds less than ordered | สินค้าขาด (`Short Pick`) | ของหาย, หยิบไม่ครบ |
| Bin Location | A storage slot | ช่องเก็บสินค้า (`Bin Location`) | ล็อกเก็บของ, ชั้นวาง |
