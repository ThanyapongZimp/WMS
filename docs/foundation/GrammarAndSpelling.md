# Grammar and Spelling

**Status:** `Trial`

This file is exempt from Vale because it lists the banned spellings on purpose.

## Transliteration

Follow the Royal Society (ราชบัณฑิตยสถาน). Vale rule: `WMS.ThaiSpelling`.

| Do | Don't |
| :--- | :--- |
| แอปพลิเคชัน | แอพ, แอป (alone as slang) |
| อีเมล | อีเมล์ |
| อัปเดต | อัพเดท, อัพเดต |
| ฟังก์ชัน | ฟังก์ชั่น |
| ดิจิทัล | ดิจิตอล |

## Spacing

Put one space before and after English words or numbers inside Thai text, except next to brackets: `ขนาดไฟล์ (MB)`.

## Numbers and dates

- Arabic digits with thousands separators: `1,250`.
- Gregorian year (ค.ศ.): `DD/MM/YYYY` or `DD เดือน YYYY`, unless a system requires พ.ศ.

## Punctuation

- No full stop after Thai text, buttons, labels or headings. Vale rule: `WMS.ThaiTrailingPeriod`.
- English uses sentence case: `Save changes`, `Log in to your account`.

## Buttons

- Start with a verb that names the result: `ยืนยันการหยิบ`, `บันทึกตำแหน่งจัดเก็บ`.
- Never use generic labels such as ตกลง or ใช่. Vale rule: `WMS.GenericButtons` (warning).
